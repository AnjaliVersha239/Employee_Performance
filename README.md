# Employee_Performance
This is my IABAC project it focuses on analyzing employee performance using data science techniques. The goal is to uncover insights, identify trends, and support better decision-making in workforce management.
# Client: INX Future Inc

The project focuses on analyzing employee data and building machine learning models to predict employee performance ratings. It aims to help HR departments make data-driven decisions to improve productivity and workforce management.
# Problem Statement

Employee performance evaluation is a critical task for organizations. This project analyzes employee data from INX Future Inc and develops predictive models to identify key factors influencing performance.

# Project Objectives
- Analyze employee demographic and job-related data
- Identify key factors affecting performance
- Perform Exploratory Data Analysis (EDA)
- Build machine learning models for performance prediction
- Provide actionable insights for HR decision-making
# Project Structure
├── Employee_Performance.ipynb   # Main notebook with analysis & models
├── README.md                   # Project documentation

# Key Insights from Analysis
- The dataset is clean (no missing or duplicate values)
- Workforce is mostly mid-career with moderate satisfaction levels
- Sales department shows high attrition, requiring management attention
- Performance varies significantly across departments
- Employee satisfaction and training opportunities are major drivers of performance
- Demographic factors (age, gender, marital status) have minimal impact

# Machine Learning Models Used
The following models were trained and evaluated:
1. Logistic Regression
2. Decision Tree
3. Random Forest  (Best performing model)
4. Support Vector Machine (SVM)

# Best Model: Random Forest
- Achieved highest accuracy
- Provided reliable predictions
- Enabled feature importance analysis

# Important Features Identified
- Top factors influencing employee performance:
- Job Satisfaction
- Promotion Gap
- Work Experience
- Training Opportunities
- Work-Life Balance

# Exploratory Data Analysis (EDA)
EDA includes:
- Department-wise performance comparison
- Attrition analysis
- Correlation analysis
- Distribution of employee attributes
- Visualization of key performance metrics


# Business Recommendations
Based on analysis:
- Improve job satisfaction and work environment
- Increase training and development programs
- Address high attrition in Sales and HR departments
- Focus on department-specific strategies instead of general policies
- Enhance career growth and promotion opportunities
